# BSP Brand Assets

This folder contains the working BSP identity assets for the `bsp-delivery-proposal` branch.

## Core idea

The BSP mark is an architectural rectangular pool: structured, measured and deliberately imperfect rather than a perfect cube. The tiled pool references cost structure and construction; the water gives the mark its distinctive visual identity.

## Assets

- `assets/bsp-pool-mark.svg` — standalone pool symbol
- `assets/bsp-wordmark.svg` — BSP wordmark
- `assets/bsp-descriptor.svg` — BUILD COST PLAN descriptor
- `assets/bsp-lockup.svg` — primary combined lockup
- Repository root `bsp-logo.svg` — proposal implementation currently in use
- Repository root `favicon.svg` — current BSP favicon

## Usage

Prefer the horizontal lockup for reports, proposals and document headers. Use the pool mark alone for favicon/app-icon scale and small graphic moments. Keep generous clear space; do not add construction-site motifs, heavy gradients, glass effects or decorative 3D treatments.

The wider brand system uses tile geometry and restrained water-plane motifs as supporting graphics. Report covers should stay minimal, information-led and editorial rather than resembling contractor/site collateral.
